# Мои расходы — Android

Локальный финансовый трекер: доходы, расходы, категории, бюджеты и история операций.
Данные хранятся в локальной базе Room на устройстве. Аккаунта и облачной синхронизации нет.

## Сборка APK через GitHub
1. Создайте новый пустой репозиторий GitHub, например `moi-rashody-android`.
2. Загрузите в него содержимое этого архива (папки `.github`, `app` и файлы Gradle должны быть в корне).
3. Откройте вкладку **Actions** и дождитесь завершения `Build APK`.
4. Откройте завершённый запуск workflow, внизу найдите **Artifacts** и скачайте `moi-rashody-debug-apk`.
5. Распакуйте архив и установите APK на Android. При необходимости разрешите установку приложений из этого источника.

## Что уже работает
- Добавление доходов и расходов вручную.
- Категории и выбор категории для операции.
- Настройка месячного лимита категории.
- Месячный баланс и сводка расходов.
- История операций.
- Локальная база Room.

## Следующий этап
QR-сканирование и распознавание бумажных чеков. Важно: QR-код российского кассового чека обычно содержит фискальные реквизиты, а не весь перечень товаров. Для получения состава чека понадобится отдельная интеграция с доступным источником электронных чеков/ОФД; простого сканирования QR недостаточно. В текущей версии раздел чеков пока не заявляет, что уже загружает товары автоматически.

## Технические требования

- JDK 17
- Android Gradle Plugin 8.7.3
